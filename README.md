# 📱 FamilyPdfReader

> A native, lightweight, and ad-free Android application designed specifically to simplify sharing and reading PDF documents within the family.

---

## ✨ Features

- **Ad-Free:** A clean interface with no pop-ups or distractions, ideal for all family members.
- **Native Document Selection:** Smooth and fast navigation across the device to instantly open PDF files.
- **Lightweight & Fast:** Developed in 100% native Kotlin to optimize performance and battery life.

## 🛠️ Tech Stack

- **Language:** Kotlin (100%)
- **Architecture:** Native Android / Android SDK
- **CI/CD:** GitHub Actions (Automated build and release pipeline)

---

## 📦 CI/CD Pipeline (Automation)

This project features an automated CI/CD workflow via **GitHub Actions** (`.github/workflows/build-apk.yml`). Whenever a version tag (e.g., `v1.0.0`) is pushed to the repository, the pipeline automatically compiles the app, renames the APK cleanly, and publishes a new GitHub Release.
